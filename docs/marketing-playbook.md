## 4. LinkedIn — publicaciones iniciales

### Post 1 — Autoridad / posicionamiento

Una web no debería existir solamente para "tener presencia".

Debería cumplir una función concreta: generar consultas, explicar mejor una propuesta, vender, automatizar un proceso o facilitar una operación.

Ese es el enfoque con el que trabajo cuando desarrollo:
- landing pages
- sitios web
- e-commerce
- aplicaciones y sistemas a medida

Primero entiendo el objetivo. Después definimos qué producto tiene sentido construir.

Armé una página donde muestro mi forma de trabajar, proyectos y servicios.

Si estás evaluando construir o mejorar un producto digital:

### Post 2 — Caso / portfolio

Un proyecto web cambia mucho cuando deja de pensarse como "una página" y empieza a pensarse como una herramienta.

En mis proyectos suelo trabajar sobre tres capas:
1. Qué necesita lograr el negocio.
2. Qué necesita entender o hacer el usuario.
3. Qué arquitectura permite que el producto pueda evolucionar.

En mi portfolio dejé algunos ejemplos de landing pages, portfolios y aplicaciones full-stack en las que trabajé.

## 9. Criterio de CRM

Pipeline:
Nuevos leads → Calificando → Contactados → Calificados → Reunión → Propuesta → Seguimiento → Ganados / Perdidos

Fuente:
- LINKEDIN: llegó a la landing desde un enlace UTM de LinkedIn.
- WHATSAPP: llegó a la landing desde un enlace UTM de WhatsApp.
- LANDING: acceso directo o sin fuente identificable.
- REFERRAL: referido identificado explícitamente.

No cambiar la fuente original aunque la conversación continúe por otro canal.

## 11. Ritmo semanal inicial

Lunes:
- Publicación LinkedIn de autoridad o educación.
- 5 contactos contextualizados.

Miércoles:
- Caso/proyecto en LinkedIn.
- Estado de WhatsApp.

Viernes:
- Publicación de oferta o disponibilidad.
- Revisión de leads y follow-ups pendientes.

No priorizar volumen masivo. Priorizar consistencia, contexto y medición.

## 12. KPIs semanales

Por canal:
- Visitas identificadas.
- Leads.
- Leads calificados.
- Reuniones.
- Propuestas.
- Clientes ganados.

Conversiones:
- Landing → lead.
- Lead → reunión.
- Propuesta → cliente.

El objetivo no es elegir un canal por cantidad de visitas, sino entender cuál genera mejores oportunidades.
